# WNIS Lab Website

A dependency-free, three-page website for GitHub Pages.

## Files to edit

- `content.js`: lab text, research areas, team members, and publications.
- `design-config.js`: colors and maximum content width.

Place new team photos in `assets/images/team/` and use lowercase, hyphenated names such as `jane-doe.jpg`.

## Pages

- `index.html`: Home and research areas
- `team/index.html`: Director and students
- `publications/index.html`: Publications grouped automatically by year

Open `index.html` to preview locally. For GitHub Pages, push this directory as the root of the lab's repository and select **GitHub Actions** under **Settings → Pages**.
